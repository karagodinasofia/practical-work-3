Опис завдання

Реалізувати функцію `eta_hours(distance_km, express)`, яка обчислює час доставки залежно від відстані та типу доставки.

Звичайна доставка триває 24 години плюс одна година за кожні повні 100 км. Для експрес-доставки отриманий час ділиться навпіл, але становить не менше 4 годин. Від’ємна відстань повинна викликати помилку.

Запуск тестів
python -m pytest -v

Перевірка покриття
python -m pytest --cov=eta --cov-report=term-missing

Функція eta_hours(distance_km, express) приймає відстань доставки в кілометрах (distance_km) і логічний параметр типу доставки (express): True — експрес, False — звичайна доставка. Функція повертає розрахунковий час доставки в годинах. Якщо відстань від’ємна, функція викликає виняток ValueError з повідомленням Distance cannot be negative.
